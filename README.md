# My Cyber Journey: 22-Week Learning Plan

Welcome to my daily learning log. I am spending the next 22 weeks (150+ days) studying core Cybersecurity foundations, scripting, and digital forensics.

This repository is my accountability tracker. I use it to log what I learn, the code I write, and the concepts I struggle with every day.

## Core Curriculum
My learning path is built around three main resources (with slight changes):

1. **[90 Days of Cyber Security](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)**
   - Covering Network+, Security+, Linux administration, Wireshark traffic analysis, Cloud (AWS/Azure), and basics of TryHackMe/HackTheBox.
2. **[30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python)**
   - Learning Python from basic syntax up through practical scripting and automation.
3. **[Digital Forensics Labs](https://github.com/frankwxu/digital-forensics-lab)**
   - Hands-on DFIR (Digital Forensics and Incident Response) practice, including memory and disk forensics.

## Cyber Journey OS (My Custom Tracker)
> **Live Dashboard:** `[Link coming soon - Pending Deployment]`

To keep myself on track, I built a custom **Cyber Journey OS** using Next.js.

**Features include:**
- **Task Tracking:** All 120+ tasks from the curriculums above are stored in a PostgreSQL database and served daily.
- **AI Quizzes:** I integrated the Google Gemini API so I can generate random 10-question quizzes for whatever topic I'm studying that day to test my memory.
- **Productivity Tools:** A built-in Pomodoro timer and habit tracker to keep my momentum going.
